นโยบายความเป็นส่วนตัว

Privacy Policy  ·  อัปเดตล่าสุด: มิถุนายน 2026

สรุปสั้น ๆ: ข้อมูลการเงินของคุณถูกเข้ารหัสบนอุปกรณ์ก่อนบันทึกบน cloud — เราอ่านไม่ได้ ข้อมูลที่แอปเก็บในเซิร์ฟเวอร์มีเพียง email สำหรับ login และสัญญาณตัวเลขสำหรับการแจ้งเตือน (ไม่มีชื่อรายการ จำนวนเงิน หรือรายละเอียดส่วนตัว)

1. ข้อมูลที่เก็บรวบรวม

ข้อมูลที่จำเป็นสำหรับการเข้าสู่ระบบ

  • Email address และ Google account ID (ผ่าน Google OAuth เท่านั้น)
  • ข้อมูลนี้ใช้เพื่อระบุตัวตนและเชื่อมกับ vault ที่เข้ารหัสของคุณ

ข้อมูล vault (ข้อมูลการเงิน)

  • ข้อมูลทุกรายการที่คุณบันทึก (รายรับ-รายจ่าย กระเป๋า งบประมาณ ฯลฯ) จะถูก เข้ารหัสด้วย AES-256-GCM บนอุปกรณ์ของคุณ ก่อนส่งขึ้น cloud
  • เราไม่สามารถอ่านข้อมูลการเงินของคุณได้ — รหัสถอดรหัสอยู่กับคุณเท่านั้น
  • ถ้าคุณไม่เปิดใช้ sync ข้อมูลจะอยู่บนอุปกรณ์ของคุณเท่านั้น

ข้อมูลสำหรับการแจ้งเตือน (ถ้าเปิดใช้)

  • Push subscription token และ device ID (ไม่มีชื่อหรือข้อมูลส่วนตัว)
  • Platform, browser name, timezone — เพื่อส่งการแจ้งเตือนถูกเวลา
  • สัญญาณตัวเลขเท่านั้น เช่น "มีบิล X วัน" หรือ "ใช้งบถึง Y%" — ไม่มีชื่อรายการ จำนวนเงิน หรือร้านค้า
  • App version และวันที่ export ล่าสุด

4. การเก็บรักษาข้อมูล

  • ข้อมูล vault เก็บไว้จนกว่าคุณจะลบบัญชีหรือลบ vault
  • ข้อมูลอุปกรณ์สำหรับการแจ้งเตือนจะถูกลบเมื่อคุณยกเลิกการแจ้งเตือนหรือลบบัญชี
  • ข้อมูลบนอุปกรณ์ (localStorage) อยู่ภายใต้การควบคุมของคุณ — ลบได้ผ่าน "รีเซ็ตข้อมูลทั้งหมด" ในการตั้งค่า หรือลบ browser data

5. สิทธิ์ของคุณ (PDPA / สิทธิ์ผู้ใช้)

📤 ส่งออกข้อมูล (Data Portability)

ใช้ฟีเจอร์ "ส่งออกข้อมูล (JSON)" ในแท็บตั้งค่าของแอป เพื่อดาวน์โหลดข้อมูลทั้งหมดของคุณในรูปแบบ JSON ที่อ่านได้

🗑️ ลบข้อมูล (Right to Erasure)

กด "รีเซ็ตข้อมูลทั้งหมด" ในแท็บตั้งค่า เพื่อลบข้อมูลทั้งหมดบนอุปกรณ์ และลบ vault บน cloud ผ่านเมนูบัญชี (ลบ vault) หรือติดต่อเราเพื่อขอลบข้อมูลทั้งหมด

👁️ เข้าถึงข้อมูล (Right of Access)

ข้อมูลการเงินทั้งหมดอยู่ในอุปกรณ์ของคุณและใน vault ที่คุณถอดรหัสได้เอง ใช้ฟีเจอร์ Export เพื่อดูข้อมูลทั้งหมด

6. ความปลอดภัย

  • ข้อมูลการเงินเข้ารหัส AES-256-GCM ก่อนออกจากอุปกรณ์
  • Key derivation ใช้ PBKDF2 (SHA-256, 310,000 iterations)
  • รหัสกู้ข้อมูล (Recovery Key) เก็บบนอุปกรณ์เท่านั้น — เราไม่มีสำเนา
  • การรับส่งข้อมูลทั้งหมดผ่าน HTTPS

7. คุกกี้และ Local Storage

แอปนี้ไม่ใช้คุกกี้ แต่ใช้ localStorage และ sessionStorage ของเบราว์เซอร์เพื่อบันทึกข้อมูลการเงินและการตั้งค่าบนอุปกรณ์ของคุณ ข้อมูลเหล่านี้ไม่ถูกส่งไปยังเซิร์ฟเวอร์ยกเว้นในรูปแบบที่เข้ารหัสแล้ว

8. ข้อมูลเด็กและผู้เยาว์

แอปนี้ไม่ได้ออกแบบมาสำหรับเด็กอายุต่ำกว่า 13 ปี เราไม่เก็บข้อมูลของเด็กโดยตั้งใจ

9. การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลงสำคัญ เราจะแสดงการแจ้งเตือนในแอปและอัปเดตวันที่ด้านบน

10. ติดต่อเรา

# Phase 4.2 Financial Position Boundary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move committed credit-installment liability composition into the canonical Ledger financial-position service without changing public App behavior.

**Architecture:** Extend the existing `MTLedger.getFinancialPosition()` contract with explicit transaction and reward dependencies. Keep `App.getFinancialPosition()` as a thin runtime adapter and keep presentation category buckets in App. Preserve explicit `committedLiabilities` as a compatibility override while deriving it when omitted.

**Tech Stack:** Plain JavaScript UMD modules, Node's built-in test runner, static source-architecture tests.

**Spec:** `docs/superpowers/specs/2026-10-06-phase4.2-financial-position-boundary.md`

## Global Constraints

- Preserve the public `App.*` interfaces used by existing screens and tests.
- Preserve existing financial results for crypto exclusion, loan receivables, wallet liabilities, and net worth.
- Derive committed liabilities only from future (not-yet-posted) transactions on non-excluded credit wallets, preserving `getCommittedInstallmentDebt()` semantics.
- Use non-persisted Ledger Amount semantics (`preferStored:false`) for the derived installment calculation.
- Do not add a runtime module or change HTML load order.

## Review Focus

- A posted installment must not contribute to committed liabilities — covered by Task 1's Ledger contract test.
- An excluded credit wallet must not contribute — covered by Task 1's Ledger contract test.
- Credit reward discounts must affect derived installment debt even when a stale `ledgerAmount` is stored — covered by Task 1's Ledger contract test.
- An explicit `committedLiabilities` override must retain precedence — covered by the existing Ledger financial-position test.
- App must not reintroduce direct liability composition — covered by Task 2's static architecture test.
